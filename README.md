# अर्पिता संग रोहित — मंगल परिणय (शुभ विवाह आमंत्रण डिजिटल वेबसाइट)

एक अत्यंत भव्य, राजसी (Royal Indian Wedding Experience), आधुनिक एवं पूर्णतः उत्तरदायी (Responsive) विवाह आमंत्रण वेबसाइट, जिसे **केवल कन्या पक्ष (अर्पिता के परिवार — विश्वकर्मा परिवार, खुरई, सागर)** की ओर से तैयार किया गया है।

---

## 🌟 मुख्य विशेषताएं (Key Features)

### १. पूर्णतः हिंदी भाषा में (100% Authentic Hindi Experience)
- वेबसाइट का प्रत्येक भाग, बटन, शीर्षक, तिथि, उल्टी गिनती (दिन, घंटे, मिनट, सेकंड), दिशा-निर्देश एवं संदेश शुद्ध व सुरुचिपूर्ण हिंदी में प्रस्तुत हैं।

### २. वैयक्तिक अतिथि URL प्रणाली (Personalized Guest URL System)
- प्रत्येक अतिथि के लिए विशेष व्यक्तिगत URL:
  - `/invite/rahul-sharma` ➔ **प्रिय राहुल शर्मा जी (सपरिवार)**
  - `/invite/amit-family` ➔ **आदरणीय अमित जी एवं समस्त परिवार**
  - `/invite/prakunj-vishwakarma` ➔ **प्रिय भ्राता प्राकुंज विश्वकर्मा जी (सपरिवार)**
- यदि कोई अतिथि बिना विशेष URL के आता है, तो सादर **"अतिथि देवो भव"** का संदेश प्रदर्शित होता है।
- **त्वरित लिंक जनरेटर:** स्क्रीन के नीचे बाईं ओर दिए गए **"वैयक्तिक लिंक बनाएं"** बटन से परिवार किसी भी नए अतिथि का नाम डालकर तुरंत नया लिंक तैयार कर सकते हैं और **१-क्लिक में व्हाट्सएप पर सुंदर निमंत्रण संदेश सहित साझा** कर सकते हैं।

### ३. राजसी कपाट अनावरण (Royal Door Opening & Shehnai Music)
- वेबसाइट खुलते ही स्वर्ण कलश, श्री गणेश जी महाराज का पावन प्रतीक एवं श्लोक के साथ राजसी कपाट प्रदर्शित होते हैं।
- **"आमंत्रण खोलें"** बटन दबाते ही दोनों कपाट भव्यता से खुलते हैं, स्वर्ण पुष्पवृष्टि होती है, और पारंपरिक **शहनाई मंगल धुन (Web Audio API)** स्वतः प्रारंभ होती है।
- संगीत को कभी भी म्यूट/अनम्यूट किया जा सकता है अथवा परिवार अपनी मनपसंद MP3 धुन भी अपलोड कर सकते हैं।

### ४. पावन पत्रिका संदेश (Bride's Family Invitation Letter)
- श्री मोहनलाल विश्वकर्मा एवं श्रीमती मोहनी की ओर से औपचारिक आमंत्रण पत्र।
- हस्तनिर्मित स्वर्ण पत्र व राजसी मेहराब शैली।

### ५. वर-वधू परिचय (Bride & Groom Profiles)
- **आयुष्मती अर्पिता (वधू):** श्री मोहनलाल विश्वकर्मा एवं श्रीमती मोहनी की सुपुत्री, श्री काशीराम विश्वकर्मा एवं स्वर्गीय श्रीमती यशोदाबाई की सुपौत्री (खुरई, जिला–सागर, म.प्र.)।
- **आयुष्मान रोहित (वर):** स्वर्गीय श्री शंकरलाल विश्वकर्मा एवं श्रीमती रजाबाई के सुपुत्र, स्वर्गीय श्री श्यामलाल विश्वकर्मा के सुपौत्र (बिजावर, जिला–छतरपुर, म.प्र.)।
- राजसी झरोखा फ्रेम एवं अपनी तस्वीरें अपलोड करने की लाइव सुविधा।

### ६. मांगलिक कार्यक्रम रूपरेखा (Wedding Events Timeline - Bride's Side)
- **२३ नवंबर २०२६ (सोमवार):** गणेश पूजन, तेल एवं मंडप (निज निवास, खुरई)
- **२४ नवंबर २०२६ (मंगलवार):** हल्दी एवं मेहंदी (निज निवास, खुरई)
- **२५ नवंबर २०२६ (बुधवार - सुबह ९:०० बजे):** कन्या सहित विवाह स्थल के लिए प्रस्थान (निज निवास, खुरई)
- **२५ नवंबर २०२६ (बुधवार - शाम ६:०० बजे से):** स्वरुचिभोज (चंद्रलोक मैरिज गार्डन, बिजावर)
- प्रत्येक कार्यक्रम के लिए **"गूगल कैलेंडर में जोड़ें"** सुविधा।

### ७. शुभ विवाह स्थल एवं सजीव उल्टी गिनती (Venue & Live Countdown)
- **चंद्रलोक मैरिज गार्डन, गुलगंज रोड, बिजावर, जिला–छतरपुर (मध्य प्रदेश)**
- गूगल मैप्स एकीकरण, दिशा-निर्देश (Get Directions) बटन।
- विवाह मुहूर्त तक के शेष समय की सजीव उल्टी गिनती (दिन, घंटे, मिनट, सेकंड)।

### ८. परिवार एवं स्वागत (Family Section)
- **विनीत:** श्रीमती मोहनी एवं श्री मोहनलाल विश्वकर्मा, श्री काशीराम विश्वकर्मा एवं समस्त विश्वकर्मा परिवार।
- दर्शनाभिलाषी, स्वागतार्थी एवं बाल मनुहार।
- परिवार के नए सदस्यों के नाम सीधे वेबसाइट से जोड़ने या संपादित करने की सुविधा।

### ९. सुखद स्मृतियाँ (Photo Gallery & Lightbox)
- वर-वधू, हल्दी-मेहंदी, विवाह रस्मों एवं पारिवारिक श्रेणियों में उच्च गुणवत्ता वाली गैलरी।
- फुलस्क्रीन लाइटबॉक्स दर्शक (Lightbox Viewer) एवं नई तस्वीरें जोड़ने का विकल्प।

### १०. आशीर्वाद पट्टिका एवं उपस्थिति सूचना (Wishes Wall & RSVP)
- सगे-संबंधी एवं मित्र नवदंपति के लिए अपना मंगल आशीर्वाद व शुभकामनाएं लिख सकते हैं।
- उपस्थिति की त्वरित पुष्टि (सपरिवार उपस्थित होंगे)।

## 🛠️ तकनीकी विवरण (Tech Stack)

- **Frontend:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS, Royal Gradients & Custom Filigree
- **Animations:** Framer Motion, Canvas Confetti
- **Audio:** Web Audio API (Indian Shehnai & Tanpura Raga Synthesizer - 100% Offline Reliable)
- **Routing:** React Router DOM (Personalized Slug System)
- **Icons:** Lucide React & Handcrafted Indian Cultural SVGs

## 🚀 स्थानीय स्तर पर चलाने की विधि (How to Run Locally)

1. प्रोजेक्ट डायरेक्टरी में जाएं:
   ```powershell
   cd c:\Users\hp\Downloads\Arpita
   ```

2. विकास सर्वर प्रारंभ करें (Development Server):
   ```powershell
   npm run dev
   ```

3. उत्पादन बिल्ड तैयार करें (Production Build):
   ```powershell
   npm run build
   npm run preview
   ```

4. ब्राउज़र में खोलें:
   - मुख्य आमंत्रण: `http://localhost:3000/`
   - राहुल शर्मा जी का आमंत्रण: `http://localhost:3000/invite/rahul-sharma`
   - अमित जी का आमंत्रण: `http://localhost:3000/invite/amit-family`
   - प्राकुंज जी का आमंत्रण: `http://localhost:3000/invite/prakunj-vishwakarma`
